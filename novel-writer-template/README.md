# Novel Writer Pro 小说创作模板

这是一个可直接用于 Cursor / Claude Code / Codex 的中文长篇小说工程模板。

## 使用方式

1. 把整个 `novel-writer-pro` 放入你的 Skill 目录。
2. 新建小说时复制整个目录作为一个小说项目。
3. 先填写 `NOVEL_BIBLE.md`。
4. 再完善 `CHARACTERS/`、`WORLD/`、`POWER/`、`PLOT/`。
5. 写作过程中持续维护 `STORY_STATE.md` 和 `FORESHADOWING/`。
6. 每章使用 `templates/chapter.md`。
7. 完成后使用 `REVIEWS/` 做检查。

## 推荐命令

可以在 Agent 中使用自然语言：

- “创建一部新小说”
- “根据这个想法建立小说圣经”
- “设计主角和主要角色”
- “设计第一卷大纲”
- “规划第 1-20 章”
- “写第 1 章”
- “继续写下一章”
- “检查前后有没有逻辑问题”
- “检查人物有没有 OOC”
- “检查战力体系”
- “检查伏笔”
- “降低 AI 味”
- “重写这一章，但不要改变剧情”

## 核心原则

小说不是一堆章节，而是：
世界 + 人物 + 规则 + 剧情 + 时间 + 伏笔 + 情绪 + 成长 + 连续性。
